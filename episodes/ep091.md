# 【第91話】一度に運べるデータ量の違い｜ITパスポート 令和4年度 問81

～ツンデレ女子大生と東大パソコンオタクの、ちょっと不器用な勉強会～

**第91話｜第4部　場所：雨宿り**

---

## 登場人物

**Ａ：美咲（みさき）**
女子大生。就活のエントリーシートの資格欄が真っ白なことに気づき、慌ててITパスポートの勉強を開始。ITは完全に素人。高校時代は可愛くて人気者だったので、ちょっとプライドが高い。素直じゃない。

**Ｂ：拓也（たくや）**
美咲の高校時代の同級生。東京大学工学部。子どもの頃からパソコンばかりいじってきた生粋のオタク。実は美咲のことが好きだが、10年近く言い出せていない。教えるのは得意だが、口が悪いのが玉に瑕。

---

## 今日の問題

> **CPU の性能に関する記述のうち，適切なものはどれか。**
>
> （ア）32ビット CPU と64ビット CPU では，64ビット CPU の方が一度に処理するデータ長を大きくできる。  
> （イ）CPU 内のキャッシュメモリの容量は，少なければ少ないほど CPU の処理速度が向上する。  
> （ウ）同じ構造の CPU において，クロック周波数を下げると処理速度が向上する。  
> （エ）デュアルコア CPU とクアッドコア CPU では，デュアルコア CPU の方が同時に実行する処理の数を多くできる。  

---

## 第1幕：通り雨のコンビニ軒先

3月、二人は帰り道で急な通り雨に降られ、コンビニの軒先で雨宿りをすることになった。スマホで雨雲レーダーを確認する。

**美咲**「あと10分くらいで止みそうね」

**拓也**「あ、それ、今日の問題にちょうどいい話だ」

**美咲**「雨宿りしてるだけなのに、また繋げるの」

**拓也**「今回は本当に、今見てるスマホのスペックがそのまま答えなんだって」

---

## 第2幕：コア数が多いほうが処理数は少ないでしょ

軒先の隅で、拓也がスマホの画面を見せながら小声で話す。

**美咲**「じゃあ答えるわね。これ……ウの『クロック周波数を下げると処理速度が向上する』……あ、待って、これ前に教わったのと逆じゃない」

**拓也**「よく気づいたね。うん、それは違う」

**美咲**「じゃあ、これ**エ**でしょ。『デュアルコアのほうが、同時に実行する処理の数を多くできる』」

**拓也**「お、なんでそう思った?」

**美咲**「なんとなく、"デュアル"のほうが、こう、集中してそうなイメージだったのよね」

**拓也**「発想は面白いんだけど、実は**コアの"数"と、同時にできる処理の"数"は、そのまま比例する**んだ。デュアルコアは2つ、クアッドコアは4つ。**多いほうが、同時にできる処理も多くなる**」

---

## 第3幕：一度に運べるデータの車線数

拓也は、スマホのスペック表を指さした。

**拓也**「ここ見て。"64bit対応"って書いてあるよね。これ、道路の車線数だと思ってみて」

**美咲**「うん」

**拓也**「**32ビットが2車線の道路だとしたら、64ビットは4車線の道路みたいなもの。一度に運べるデータの量（データ長）が、64ビットのほうが大きくなる**んだ」

**美咲**「あ……! 　ビット数が大きいほど、一度に処理できるデータの幅が広くなるってことね」

**拓也**「**そのとおり。正解はア**。**64ビットCPUのほうが、32ビットCPUより、一度に処理するデータ長を大きくできる**。イのキャッシュメモリも、ウのクロック周波数も、エのコア数も、"多い・大きい・速いほうが基本的に性能が上がる"のが自然な流れなんだ」

**美咲**「なるほどね……。今日の選択肢、ほとんど"逆のこと"が書いてあったのね」

雨脚が強まってきたのを見て、拓也が慌てて立ち上がった。

**拓也**「……あ、俺、傘持ってきてない。ちょっと買ってくる」

**美咲**「え、わざわざいいのに」

**拓也**「すぐ戻る」

拓也はコンビニに駆け込んだが、しばらくして手ぶらで戻ってきた。

**拓也**「……あ、売り切れてる」

**美咲**「あはは、それは残念だったわね」

**拓也**「面目ない……。空振りでした」

**美咲**「まあ、もう少しで止みそうだし、このまま待ちましょ」

**拓也**「うん、そうする」

二人は軒先に並んで立ったまま、弱まっていく雨を眺めていた。

## 第5幕：残りの選択肢を片付ける

雨足が落ち着いてきた頃、拓也が続きを説明する。

**美咲**「……気を取り直して。残りの**イ**と**ウ**も教えて」

**拓也**「イの『キャッシュメモリは少ないほど処理速度が向上する』は、**逆**。キャッシュメモリは、CPUがよく使うデータを一時的に置いておく場所だから、**容量が大きいほうが、処理速度は基本的に向上する**んだ」

**美咲**「ウは?」

**拓也**「ウの『クロック周波数を下げると処理速度が向上する』も、**逆**。前に話したとおり、**クロックの間隔が短い（周波数が高い）ほど、処理は速くなる**んだったよね」

**美咲**「ビット数もキャッシュもクロックもコア数も、全部"多い・大きい・速いほうが性能が上がる"の法則どおりなのね。今日の問題、逆のことばっかり並んでたから、ある意味わかりやすかったかも」

**拓也**「**完璧な整理**。この手の問題は、"基本は数字が大きいほうが高性能"って前提を持っておくと、ひっかけに惑わされにくくなるよ」

---

> **CPU の性能に関する記述のうち，適切なものはどれか。**
>
> （ア）32ビット CPU と64ビット CPU では，64ビット CPU の方が一度に処理するデータ長を大きくできる。  
> （イ）CPU 内のキャッシュメモリの容量は，少なければ少ないほど CPU の処理速度が向上する。  
> （ウ）同じ構造の CPU において，クロック周波数を下げると処理速度が向上する。  
> （エ）デュアルコア CPU とクアッドコア CPU では，デュアルコア CPU の方が同時に実行する処理の数を多くできる。  

## まとめ：選択肢ごとの答え合わせ

| 選択肢 | 内容 | 正誤 |
|---|---|---|
| **ア** | **64ビットCPUの方が一度に処理するデータ長を大きくできる** | **正解** |
| イ | キャッシュメモリは少ないほど処理速度が向上する（逆） | 不正解 |
| ウ | クロック周波数を下げると処理速度が向上する（逆） | 不正解 |
| エ | デュアルコアの方が同時実行数を多くできる（逆） | 不正解 |

**答え：ア　32ビットCPUと64ビットCPUでは，64ビットCPUの方が一度に処理するデータ長を大きくできる**

---

## 覚え方のコツ

> **32ビットは2車線、64ビットは4車線。広いほうが、一度にたくさん運べる。**

- ビット数が大きいCPUほど、一度に処理できるデータ長（車線数）が大きい
- キャッシュメモリは容量が大きいほど、クロック周波数は高いほど、コア数は多いほど、それぞれ処理速度・並列性能が向上する
- 「数字が大きい・多いほうが基本的に高性能」という前提を持つと、逆さまのひっかけ選択肢に惑わされにくい

## エピローグ

雨が止み、二人は水たまりを避けながら歩き出した。

**美咲**「今日は、あんたの傘、無駄足だったわね」

**拓也**「返す言葉もございません……。次からは、天気予報ちゃんと見ておく」

**美咲**「そうしなさい。……でも、走って買いに行こうとしてくれたのは、ちょっと嬉しかったけど」

**拓也**「え、そうなの?」

**美咲**「……別に、深い意味はないから」

**拓也**（……深い意味はなくても、素直にそう言ってくれるの、地味に破壊力あるんだけどな）

**美咲**「なに黙ってるのよ」

**拓也**「いや、なんでもない。……傘、今度こそちゃんと持ってくる」

**美咲**「うん、頼りにしてる」

濡れたアスファルトに夕日が反射する中、二人は駅までの道を歩いていった。

---

## 今日のポイントおさらい

1. **64ビットCPUの方が、32ビットCPUより一度に処理するデータ長を大きくできる**
2. キャッシュメモリは、容量が大きいほど処理速度が向上する
3. クロック周波数は、高いほど処理速度が向上する
4. コア数は、多いほど同時に実行できる処理の数が増える
5. CPU性能の問題は、**「数字が大きい・多いほうが基本的に高性能」という前提**を持つと惑わされにくい
