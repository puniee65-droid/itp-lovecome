## 第2幕：格安SIMの罠

**美咲**「えっと……問題文に『スマートフォン』って書いてあるでしょ。スマホといえば……あ、**ア　MVNO**！」

**拓也**「お、なんでMVNO？」

**美咲**「これ聞いたことある！　格安SIMのやつでしょ？　友達がスマホ代安くしたいって言ってて」

**拓也**「よく知ってるね。でも残念、それは通話の技術じゃなくて『**携帯電話サービスの提供のしかた**』の話なんだ」

**美咲**「え、違うの？」

**拓也**「**MVNO＝Mobile Virtual Network Operator**、日本語だと『仮想移動体通信事業者』」

**美咲**「日本語のほうがわからないんだけど」

**拓也**「だよね。ざっくり言うと、**ドコモやauから電波を借りて、自分のブランドでスマホサービスを売ってる会社**のこと。自社で電波塔を建ててるのがMNO（ドコモ・au・ソフトバンク・楽天）で、そこから間借りしてるのがMVNO」

**美咲**「間借り……」

**拓也**「そう。自分で建物を建てずに、テナントとして入ってるイメージ。自社で設備を持たないぶん安くできる。これが格安SIMのカラクリ」

**美咲**「……なるほど。じゃあ通話の技術じゃないってことね」

**拓也**「うん。**問題文が聞いてるのは『技術』であって『会社の形態』じゃない**。ここを読み分けられるかどうかは大事」

## 第3幕：over は「経由」

**拓也**「じゃあヒント出すね。答えは**エ　VoIP**」

**美咲**「ぶいおーあいぴー？　なにそれ、一番わからないやつなんだけど」

**拓也**「これがさっき言った『正式名称に答えが書いてある』パターン。**VoIP＝Voice over Internet Protocol**」

**美咲**「Voice……声？」

**拓也**「そう、Voiceは声。Internet Protocolはインターネットの通信ルール。で、真ん中の**over が『〜を経由して』**っていう意味」

**美咲**「……あ。**インターネット経由の、声**？」

**拓也**「**そういうこと！**　まさにそれ。つまりVoIPは『インターネット回線を使って音声通話をする技術』。LINEの無料通話とかSkypeとか、あれ全部VoIPだよ」

**美咲**「えっ、LINE通話ってそんな大層な技術だったの？　毎日使ってるんだけど」

**拓也**「毎日使ってる技術が試験に出てるって、けっこう面白くない？」

**美咲**「……たしかに、ちょっと面白い」

**拓也**「ちなみに『over』が入ってる用語はけっこうあって、全部『〜経由』で読めるんだ。**Video over IP**ならIP経由の映像。この読み方を覚えておくと、初見の用語でも意味が推測できるようになる」

**美咲**「へえ……。英語、ちゃんとやっとけばよかった」

## 第4幕：拓也、また口を滑らせる

**美咲**「でもさ、ひとつ疑問なんだけど」

**拓也**「なに？」

**美咲**「**普通の電話って通話料かかるのに、LINE通話はなんでタダなの？**　同じ『しゃべる』なのに」

**拓也**「うわ、そこ気になる？　いい着眼点だな……よし、じゃあちょっと本気で説明するね」

**美咲**「（あ、目が輝いた）」

**拓也**「昔ながらの電話は**回線交換方式**っていって、AさんとBさんの間に**専用の通り道を1本まるごと確保する**んだ。通話中はその道は他の誰も使えない。貸し切り。だから『何分使いましたか？』で料金が決まる」

**美咲**「タクシーみたいな感じ？」

**拓也**「近い！　むしろ『**通話してる間ずっと、道路を1車線借り切ってる**』ってイメージかな。贅沢でしょ」

**美咲**「たしかに高そう」

**拓也**「一方でVoIPは**パケット交換方式**。声をデジタルデータに変換して、**小包（パケット）に小分けにして**、みんなが使ってるインターネットに流すんだ。届いた先で小包を並べ直して、また声に戻す」

**美咲**「小分け……宅配便みたいね」

**拓也**「そう！　道路を借り切らずに、他の荷物と一緒に相乗りさせてもらう。だから**専用の道路代がかからない**。しかもインターネットって定額でしょ？　だから通話が実質タダになる」

**美咲**「……あー！　そういうことか！　すごい、腑に落ちた！」

**拓也**「しかも相乗りだから距離も関係ない。だから**海外にかけても無料**。国際電話が1分何百円だった時代を知ってると、これは本当に革命で——」

**美咲**「ふうん」

**拓也**「——ちなみに欠点もあって、道路が混んでると小包が遅れたり、順番が入れ替わったり、最悪ちょっと落ちたりする。LINE通話で声が途切れるのはそれ。あと停電に弱い。固定電話は電話線から電気もらってるから停電でも使えるけど、VoIPはルーターが死んだら終わり。だから災害時には——」

**美咲**「……ねえ」

**拓也**「——あ、それと050で始まる番号あるでしょ、あれもIP電話で、企業の内線とかもいまはほとんどVoIPに置き換わってて、コールセンターなんかは全部——」

## まとめ：選択肢ごとの答え合わせ

| 選択肢 | 正式名称 | 意味 | 身近な例 |
|---|---|---|---|
| ア　MVNO | Mobile Virtual Network Operator | 大手から回線を借りてサービスを提供する事業者 | 格安SIM各社 |
| イ　NFC | Near Field Communication | 数センチの近距離無線通信 | Suica、おサイフケータイ |
| ウ　NTP | Network Time Protocol | 時刻を正確に同期させる仕組み | スマホの時計の自動調整 |
| **エ　VoIP** | **Voice over Internet Protocol** | **インターネット経由の音声通話** | **LINE通話、Skype、050番号** |

**答え：エ　VoIP**

---

## 覚え方のコツ

> **略語は、まず正式名称にほどく。**

- **Vo-IP** → **Voice over IP** → 「IP経由の声」
- **N-F-C** → **Near Field** → 「近い範囲」
- **N-T-P** → **Time** → 「時刻」
- **MVNO** → **Virtual** → 「仮想＝自前じゃない＝借りてる」

**拓也**「ITパスポートの略語問題は、**英単語1個が拾えれば正解できる**ものがすごく多い。全文覚えなくていいから、キーワードだけ拾う癖をつけるといいよ」

**美咲**「Voiceが拾えたら、それはもう通話の話だろ、ってことね」

**拓也**「そういうこと。完璧」

### おまけ：VoIPのメリットとデメリット

| | 内容 |
|---|---|
| メリット | 通話料が安い／距離に関係なく同料金・無料／既存のネット回線を使い回せる |
| デメリット | 回線が混むと音が途切れる・遅れる／停電やルーター故障に弱い／110番などの緊急通報に制限がある場合がある |

**拓也**「メリットだけじゃなくてデメリットもセットで覚えると、応用問題にも対応できるよ」

## 今日のポイントおさらい

1. **VoIP＝Voice over Internet Protocol＝インターネット経由の音声通話**
2. **over は「〜を経由して」**。略語は正式名称にほどけば意味が見える
3. 従来の電話は**回線交換方式**（道を貸し切り）、VoIPは**パケット交換方式**（相乗り）。だから安い
4. MVNOは「技術」ではなく「事業者の形態」。**問題文が何を聞いているかを読む**
5. NFCは数センチ（Suica）、NTPは時刻合わせ。どちらも通話とは無関係
