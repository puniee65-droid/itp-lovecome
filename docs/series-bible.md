# シリーズ設定書｜ITパスポート ラブコメ解説【全108話構成】

**シリーズ名（仮）**：ツンデレ女子大生と東大パソコンオタクの、ちょっと不器用な勉強会

このファイルは、第3話以降を別セッション・別モデル（Sonnet 5 等）で書き継ぐための設定書です。
**新しい話を書くときは、このファイル＋直近2〜3話のMDを必ず読み込ませてください。**

---

## 0. このシリーズの狙い

ITパスポートの過去問解説はnote上でレッドオーシャンです。正攻法の解説記事は、専門学校教員の有料noteや大手過去問サイトに検索流入で勝てません。

**そこで本シリーズは「解説の質」ではなく「続きが読みたいか」で勝負します。**

- 検索流入ではなく、**note内の回遊・フォロー・シリーズ読破**で読まれることを狙う
- 読者が覚えて帰るのは「用語の定義」ではなく「比喩」と「掛け合い」
- **美咲の合格までを縦軸**に置き、1問1話でも離脱しにくい連載構造にする

> **判断に迷ったときの基準**：「試験対策として正しいか」より先に「読み物として面白いか」を問う。
> ただし**技術的な誤りだけは絶対に許容しない**（§11のチェックリスト参照）。

## 1. 全体構成（全108話）

### 1-1. なぜ108話か

**ITパスポート試験は100問構成**（ストラテジ系35問／マネジメント系20問／テクノロジ系45問）。
本編100話で1問ずつ扱えば、**読破＝試験1回分の全範囲網羅**になります。
これに合格発表後のエピローグ編8話を足して、全108話とします。

## 2. 登場人物

### Ａ：美咲（みさき）／女子大生

| 項目 | 設定 |
|---|---|
| 学年 | 大学3年（開始時）。第4部の終わりで4年に進級 |
| 動機 | 就活のエントリーシートの資格欄が真っ白で、慌ててITパスポートの勉強を開始 |
| ITレベル | 完全な素人。スマホとレポート作成にしかPCを使わない |
| 性格 | 高校時代は可愛くて人気者。プライドが高く、素直じゃない。いわゆるツンデレ |
| 弱点 | わからないことを認めるのが苦手。バカにされると本気で怒る。**挫折に弱い** |
| 長所 | **地頭は悪くない**。比喩で説明されると一発で理解する。素朴な良い質問をする |
| 苦手分野 | **ストラテジ系**（経営・法務）。興味が持てず後回しにする癖がある ← 1回目不合格の伏線 |

**口調サンプル**

> 「ちょっと、拓也。……その、来てあげたわよ」
> 「べ、別に用があるわけじゃないんだけど」
> 「な、なによその顔。しょうがないじゃない」
> 「……教えてくれない？　た、ただの人助けだと思ってくれていいから」
> 「なっ、なんでそんなに食い気味なのよ気持ち悪い！」
> 「……ふふん。私、けっこう飲み込みいいんじゃない？」
> 「あ、やだ〜」
> 「いや〜ん」
> 「だめー」
> 「助けて〜」
> 「あ〜ん」

**書くときのコツ**
- 語尾は「〜わよ」「〜じゃない」「〜なの」。ただし**多用しすぎると古臭くなる**ので、素の「〜だけど」「〜でしょ」を混ぜる
- 照れると「なっ、」「べ、別に」と冒頭で詰まる
- **理解した瞬間だけは素直に喜ぶ**。ここが可愛さの核。「あー！　そういうことか！」
- 直後に我に返って照れ隠しする

### Ｂ：拓也（たくや）／東京大学工学部

| 項目 | 設定 |
|---|---|
| 立場 | 美咲の高校時代の同級生。東大工学部。第3部から研究室配属 |
| ITレベル | 子どもの頃からPCオタク。知識も説明力も本物 |
| 性格 | 基本は優しく面倒見がいい。ただし**知識欲が暴走すると周りが見えなくなる** |
| 弱点 | 悪気なく相手を見下す発言をする／早口で語りすぎる／恋愛方面は完全に不器用 |
| 美咲への感情 | 高校時代からずっと好き。10年近く言い出せていない |
| 第3部の葛藤 | **「美咲が合格したら、会う口実が消える」**ことに気づいてしまう |

**口調サンプル**

> 「うわっ、美咲!? どうしたの急に」
> 「いいよ、全然！　むしろやらせて！」
> 「**いい質問！**」（美咲が本質的な疑問を投げたときの定番リアクション）
> 「……ごめん。ほんとにごめん。楽しくなっちゃって」
> 「返す言葉もございません」

**書くときのコツ**
- 説明はうまい。**比喩を必ず1つ以上出す**のが拓也の芸風
- 心の声は `**拓也**（……）` の形式で。ここでだけ本音の恋愛感情を出す
- 好意はセリフで直接言わせない。**行動と心の声だけ**で表現する（終章まで）

### 2-3. デレ度メーター（部ごとの関係性の温度）

書き手が迷わないよう、**各部で美咲の態度を数値管理**します。

| 部 | ツン : デレ | 具体的な現れ方 |
|---|---|---|
| 第1部（1〜28） | **8 : 2** | 呼び出されないと来ない。「別に」「たまたま」が口癖。デレは最後の1行だけ |
| 第2部前半（29〜35） | **3 : 7** | 不合格で防御が崩れる。初めて弱音を吐く。**シリーズ最大の転換点** |
| 第2部後半（36〜50） | **6 : 4** | 立て直すが、以前ほど強がらなくなる。自分から連絡するようになる |
| 第3部（51〜78） | **5 : 5** | 勉強以外の話もするようになる。拓也の変化に気づき始める |
| 第4部（79〜100） | **4 : 6** | 拓也を頼るのが自然になる。ただし「終わり」が近いことに二人とも触れない |
| 終章（101〜108） | **2 : 8** | 素直。ただし最後の最後で照れて茶化す |

> **重要**：デレは一直線に上がりません。第2部前半で急上昇したあと、第2部後半で**少し戻します**。
> 「弱っているときだけ素直だった」という揺り戻しがあるほうが、キャラクターとして自然です。

## 3. 場所の設計

### 3-1. 場所選びの原則

1. **題材 → 場所の順で選ぶ**（原則）。「今日はデータベースだから図書館」のように、解説内容に場所が奉仕する
2. **例外：季節イベントは場所先行でよい**（学園祭・海・花火大会など）。その場合は場所に合う題材を後から選ぶ
3. **同じ場所は最低10話空ける**。連続で同じ場所は禁止
4. **季節と場所を矛盾させない**（§1-2の季節表を参照。冬に海水浴はしない）
5. **場所は「その場にある物」で説明に使う**。ファミレスならドリンクバー、コンビニならレジ。これが拓也の比喩を新鮮に保つ最大の武器

### 3-2. 場所 × 題材 対応表

| 場所 | 相性の良い題材 | 使える演出・小道具 |

## 5. 1話の作り方（手順）

1. **問題を選ぶ** … 分野配分（§1-3）と話数管理表（§14）を見て、偏りを確認
2. **場所を決める** … §3-2の対応表から、題材に合い、直近10話で使っていない場所を選ぶ
3. **誤答を設計する** … 記事のフック。**「素人がやりそうで、かつ面白い間違い」**を先に決める
4. **比喩を1つ決める** … **その場所にある物を使う**。未使用のものを選ぶ（§6参照）
5. **拓也の失言を決める** … 未使用のパターンを選ぶ（§7参照）
6. **オチを決める** … その回の用語が関係性の進展に絡む形にする（§8参照）
7. 本文を書く
8. **§11のチェックリストで検算する**
9. **§6・§7・§8・§14に今回使ったネタを追記する**

## 6. 使用済み比喩リスト（重複禁止）

| 話 | 対象 | 比喩 |
|---|---|---|
| 第1話 | DRAMのコンデンサ | 穴の空いたバケツ／水を注ぎ続けないと空になる |
| 第1話 | メモリとストレージ | **まな板と冷蔵庫**（シリーズ看板比喩。再言及は可、再説明は不可） |
| 第1話 | ROM | 石碑に彫る |
| 第2話 | 回線交換方式 | 通話中ずっと道路を1車線借り切る／タクシー |
| 第2話 | パケット交換方式 | 声を小分けの宅配便にして相乗りさせる |
| 第2話 | MVNO | 自分でビルを建てず、テナントとして間借りする |
| 第2話 | NFCが数センチしか届かない | 1メートル届いたら改札の横を通るだけで引き落とされる |
| 第2話 | NTP | 縁の下の力持ち |
| 第3話 | 商品商標とサービスマークの違い | ノベルティを配れる会社／パンフレットしか配れない会社 |
| 第4話 | ソーシャルエンジニアリング | 泥棒が鍵をピッキングせず「鍵、貸して」と頼む |
| 第5話 | デジタル署名 | 透明な袋に割り印（中身は読めるが、本人証明と改ざん検知はできる） |
| 第6話 | POP3 | 私書箱に手紙を「取りに行って持ち帰る」配達員 |

## 10. 不合格エピソードの書き方（特に重要）

第29〜33話は本シリーズの心臓部です。以下を厳守してください。

**やること**

- 美咲の悔しさを**具体的な数字**で描く（615点／285点）。抽象的な「ダメだった」にしない
- 泣く場面は**短く**。長く書くと重くなりすぎる
- 拓也が**すぐに正しい言葉を見つけられない**こと。有能さを封印する
- 第33話の説得は、**論理ではなく約束**で行う。拓也は説明が得意なキャラだが、ここでは説明が通用しない
- **記事としての解説パートは通常どおり続ける**。物語が重くても、読者は学習目的で読んでいる

**やってはいけないこと**

- ❌ 拓也が失言する（この区間だけは絶対に）
- ❌ 拓也が「だから言ったのに」と言う
- ❌ 告白する、または告白めいた言葉を言う
- ❌ 美咲が簡単に立ち直る（**4話かけて**立ち直らせる）
- ❌ 不合格をギャグとして処理する
- ❌ 試験制度を不正確に描く（分野別基準点は実在の制度。正確に）
